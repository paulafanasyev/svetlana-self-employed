# МИР САМОЗАНЯТЫХ — СВЕТЛАНА

![Мир Самозанятых](web/public/logo-mir-samozanyatykh.svg)

Единая цифровая платформа АНО «Центр поддержки самозанятых «Мир Самозанятых» для работы, развития и профессионального взаимодействия самозанятых.

## О проекте

«Мир Самозанятых» объединяет в одном продукте рабочие инструменты, возможности поиска работы и заказов, обучение, региональную навигацию, развитие собственных проектов, документы, CRM и Светлану — интеллектуального оператора проекта.

Проект создаётся для того, чтобы самозанятому не приходилось собирать рабочий процесс из множества разрозненных сервисов.

## Что делает Светлана

Светлана помогает разбирать задачи, составлять план, работать с документами и рабочими данными, искать возможности, обращаться к подключённым инструментам и проверять фактический результат действий.

Важные операции проходят через серверный контур авторизации, политики безопасности, подтверждения и проверки результата.

Модельный слой Светланы является частью закрытого серверного контура и может заменяться по мере развития собственной модели без изменения пользовательского интерфейса и бизнес-логики продукта.

## Основные разделы

- Работа, вакансии, проекты и услуги
- Обучение, подготовка и переподготовка
- Региональные возможности и меры поддержки
- CRM, документы, календарь и задачи
- Финансы и НПД-инструменты
- Маркетплейс
- Проекты самозанятых
- Светлана и интеллектуальная автоматизация
- Безопасность и приватность
- Административный внутренний отчёт по использованию сайта

## Архитектура

`backend/` — серверная часть, авторизация, данные, рабочие сервисы и контур Светланы.

`web/` — web-интерфейс.

`android/` — Android-приложение.

Секреты и параметры серверного модельного контура не хранятся в frontend или APK.

## Разработка

Требуется Node.js 22+.

```bash
npm install
cp backend/.env.example backend/.env
npm run migrate
npm test
npm run build
```

## Production

Рабочий backend должен предоставляться через HTTPS. URL backend задаётся конфигурацией окружения и не зашивается в исходный код клиента.

Для Android production URL передаётся через Gradle property:

```bash
cd android
gradle assembleRelease -PmirApiBaseUrl=https://example.invalid/api/v1
```

В релизном окружении значение задаётся закрытой конфигурацией сборки.
