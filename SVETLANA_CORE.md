# Одна Светлана для всех сайтов

Модель, характер и знания живут в одном месте: в backend «Мира Самозанятых»
(`backend/src/ai/sites.js`, маршрут `/api/v1/assistant`). Сайты не ходят в модель
сами, а спрашивают Светлану через этот сервер. У каждого сайта свой профиль темы.

| Сайт | Профиль | Что может |
|---|---|---|
| Мир Самозанятых | `mir` | работа самозанятого на платформе: заказы, CRM, документы, НПД, гранты |
| АИКО маркетплейс (Svetlana-App) | `aiko` | товары и услуги АИКО, заказы, доставка, кабинет продавца |
| Я-Зарядка AI | `zaryadka` | говорит как Пико: зарядка, привычки, учёба по шагам, рисование; детский режим |
| Светлана Репетитор | `repetitor` | школьные предметы, ОГЭ/ЕГЭ, помощь учителю; без готовых решений и ГДЗ |
| Svetlana 2.0 (Windows) | `svetlana2` | полный режим: писать код, управлять командой, вести все проекты |

Код и управление командой есть только в `svetlana2`. Остальные профили жёстко
держат тему и не отправляют на сторонние сайты: инструкция плюс фильтр ответа.

## Как подключить сайт

1. Придумать длинный случайный ключ (32+ символа) для сайта.
2. На сервере Светланы добавить переменную `ASSISTANT_KEY_<САЙТ>`
   (`ASSISTANT_KEY_MIR`, `ASSISTANT_KEY_AIKO`, `ASSISTANT_KEY_ZARYADKA`,
   `ASSISTANT_KEY_REPETITOR`, `ASSISTANT_KEY_SVETLANA2`).
3. На сервере сайта (Vercel или VPS) положить тот же ключ и адрес Светланы.
   В браузер ключ не попадает.
4. Запрос с сервера сайта:

```
POST https://<сервер Светланы>/api/v1/assistant/<сайт>/chat
Authorization: Bearer <ключ сайта>
{ "message": "…", "history": [{ "role": "user", "content": "…" }] }
→ { "site": "<сайт>", "content": "…" }
```

Нет ключа в окружении — профиль выключен (503), а не открыт для всех.
Проверка: `GET /api/v1/assistant/sites` показывает, какие профили включены.
