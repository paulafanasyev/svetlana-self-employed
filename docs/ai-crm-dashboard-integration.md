# AI CRM dashboard — адаптация для «Светланы — Мир Самозанятых»

## Решение

Референс: [AI CRM dashboard на 21st.dev](https://21st.dev/@larsen66/templates/ai-crm-dashboard), демо: https://21st-crm.vercel.app/opportunities.

В репозитории уже есть собственная CRM и серверная синхронизация. Поэтому вместо замены проекта отдельным чужим full-stack приложением адаптируется существующий интерфейс: это сохраняет авторизацию «Мира Самозанятых», данные CRM, команды Светланы и совместимость с клиентами Windows/Android.

## Сопоставление функций

| Референс | Реализация в проекте |
|---|---|
| Accounts / contacts | Контакты, компании и клиенты в текущей CRM |
| Deal pipeline | Сделки и этапы воронки |
| Tasks | Задачи и активности |
| Notes / shared lists | Заметки и история контактов; shared lists требуют отдельного уточнения модели и прав доступа |
| AI chat with record mentions | Командная панель Светланы; запись/изменение проходит через подтверждение пользователя |
| Email sign-in / Postgres | Не переносится из шаблона: используется существующий auth/backend и схема проекта |

## Что меняется этим коммитом

Файл web/src/crm/crm-light.css: более выраженная иерархия dashboard, аккуратные карточки, скругления, состояния кнопок и вкладок, адаптация под мобильные экраны и учёт prefers-reduced-motion. Бизнес-логика и формат данных CRM не меняются.

## Лицензирование и ограничения

Страница 21st.dev указывает, что исходный код шаблона доступен для скачивания в рамках платного плана. Этот PR не копирует исходный код шаблона и не утверждает, что его исходники установлены; используется визуальная адаптация по доступному публичному превью. Если нужен именно оригинальный шаблон, его необходимо получить через разрешённый план 21st.dev и проверить условия лицензии до включения.

## Проверки

После открытия PR необходимо дождаться GitHub Actions и проверить опубликованный preview вручную: экран CRM, вкладки, мобильную ширину, создание/редактирование контакта, сделки, задачи и сохранение/синхронизацию. Одно лишь изменение CSS не подтверждает runtime-проверку.
